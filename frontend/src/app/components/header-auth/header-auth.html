Présentation du projet

ISEN SecureExam est une plateforme académique permettant de préparer, générer et appliquer des environnements Linux sécurisés pour les examens. Le projet couvre la configuration des paquets autorisés, des droits système, des accès réseau, ainsi que la récupération des rendus étudiants.

Cadre académique

Ce projet est réalisé dans le cadre d’un projet bureau d’étude ISEN 2025-2026. Il a pour objectif de proposer une solution reproductible, sécurisée et exploitable pour la configuration d’environnements d’examen sous Linux.

Technologies utilisées

Angular FastAPI SQLite NixOS Python Linux Scripts client SecureExam
Cette application est développée dans un cadre pédagogique et démonstratif. Toute mise en production nécessite une validation technique, réseau et sécurité par l’établissement.
